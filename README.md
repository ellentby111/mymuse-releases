# MyMuse

网易云音乐的 Windows 桌面版：歌单、听歌统计、歌词桌宠，还有一个能用手机点歌的 KTV。

程序和你的数据是分开的——**程序**在这个页面下载，**歌单 / 歌词 / KTV 伴奏 / 登录状态**只存在你自己的电脑上，不会上传到任何服务器。

- **我的歌单**：登录后读你自己的网易云歌单，可以播放、收藏、整理。
- **听歌统计**：按歌手、时间、次数看自己的听歌记录。
- **歌词桌宠**：把当前播放的歌词放到桌面上，可拖动、可隐藏。
- **KTV**：本地伴奏 + 逐句歌词标注（支持双人歌词分色），手机扫码在同一局域网里点歌、切歌。

打开 **[最新版本页面](https://github.com/ellentby111/mymuse-releases/releases/latest)**，在页面下方的 **Assets** 里下载这个文件：

| --- | --- |
| `MyMuse-<版本号>-win.zip` | **完整安装包**，新用户只下这一个（约 63 MB） |

| 不用下 | 用途 |

历史版本都在 [Releases](https://github.com/ellentby111/mymuse-releases/releases) 里，向下翻能看到每个版本改了什么。

## 系统要求

- **Windows 10 / 11（64 位）**。
- **不需要安装 Node.js**：安装包里自带运行环境。
- **不需要装浏览器**：界面用系统自带的 WebView2 打开；如果机器上确实没有 WebView2，会自动改用本机的 Chrome / Edge 显示。
- **磁盘空间**：程序约 143 MB；之后 KTV 的伴奏和歌词会存在数据目录里，用多少占多少。

## 安装（三步）

### 1. 解压到一个"自己能写"的目录

右键 zip →「全部解压缩」，目标目录建议：

```
%LOCALAPPDATA%\Programs\MyMuse
```

或者 `D:\Apps\MyMuse` 这类普通目录也可以。

> ⚠️ **不要放在 `C:\Program Files`、`C:\Program Files (x86)` 这类需要管理员权限的位置**。放在那里程序能启动，但自动更新和数据迁移会失败。

### 2. 双击 `启动 MyMuse.vbs`

解压后的目录里找到 **`启动 MyMuse.vbs`**，双击它。

- 如果 Windows 弹出「**是否运行此脚本**」，选「是」。这个脚本只做一件事：启动同目录里的 `node.exe`，不会联网下载任何东西。
- 如果弹出「**Windows 已保护你的电脑**」（SmartScreen，因为程序没有购买代码签名），点「**更多信息**」→「**仍要运行**」。

### 3. 等启动画面走完

第一次启动要建本地服务、整理数据，启动画面可能停十几秒，属于正常现象；之后每次启动都会快很多。

启动后：

- 窗口出现，桌宠一起出现在桌面上。
- 开始菜单里会自动多一个 **MyMuse** 快捷方式，以后从开始菜单启动即可。

## 第一次打开

**登录**：在应用内扫码登录网易云音乐。登录状态只保存在本机数据目录里。

**数据放在哪**：`%LOCALAPPDATA%\MyMuse`

```
%LOCALAPPDATA%\MyMuse\
├─ data\       歌单、听歌记录、KTV 伴奏与歌词、登录凭据
├─ logs\       日志（出问题时看这里）
└─ settings.json  设置（含窗口位置、模型密钥等）
```

应用内「设置 → 数据与关于」里，数据目录那一行右边有「打开目录」，可以直接跳过去。

**桌宠**：右上角的桌宠按钮可以显示 / 隐藏。

**KTV 手机点歌**：进入 KTV →「手机点歌」，手机连**同一个 Wi-Fi**，扫屏幕上的二维码即可点歌。

端口固定为 **58971**。如果手机打不开页面，在安装目录里右键「以管理员身份运行」一次 `allow-phone.cmd`（给防火墙放行），再试。

## 更新

两种方式，数据都不会丢（数据在 `%LOCALAPPDATA%\MyMuse`，不在安装目录里）：

1. **应用内更新（推荐）**：设置 → 数据与关于 →「应用版本」→「立即更新到 x.y.z」。只下载有变化的文件，通常几 MB，更新完自动重启。如果新版本没起来，会自动回滚到旧版本。
2. **手动更新**：下载新版整包，解压后覆盖到原来的安装目录。

## 卸载

1. 托盘图标右键 →「退出」（或在应用内退出）。
2. 删除安装目录。
3. 如果想连数据和歌单一起清掉，再删除 `%LOCALAPPDATA%\MyMuse`。

> ⚠️ 删 `%LOCALAPPDATA%\MyMuse` 会把歌单、听歌记录、KTV 伴奏、歌词标注、登录状态一起删掉，删之前确认一下。

## 隐私

- 歌单、歌词、KTV 伴奏、账号登录状态都只保存在本机，**不上传**。
- 检查更新只是向 GitHub 发一个匿名 `GET` 请求（不带账号、不带 cookie、不带机器码），没有遥测，也不会上传或下载你的数据目录。
- 手机点歌只在你自己的局域网内通信，不经过外网服务器。

## 常见问题

**双击后没反应 / 窗口没出来**
先看日志：`%LOCALAPPDATA%\MyMuse\logs\host.log` 和 `mymuse.log`。也可以在安装目录打开命令行运行下面这条，错误会直接打出来：

```bat
node.exe app\desktop\launcher.mjs
```

**安全软件拦截了 VBS**
允许它运行，或者用上面那条命令行启动。

**开机后想直接打开**
从开始菜单点 MyMuse。如果快捷方式没了，重新双击一次 `启动 MyMuse.vbs` 会自动补上。

**换了新电脑，想把歌单和 KTV 搬过去**
数据在 `%LOCALAPPDATA%\MyMuse`，复制整个目录过去即可；程序在新电脑上按上面的步骤装一遍。

**多个电脑之间的曲库同步**
应用内「设置 → 数据与关于 → 曲库同步（局域网）」提供源机 / 从机配对，两台电脑连同一个局域网直连传输，不经过服务器；Cookie、账号和大模型 Key 不会被同步。
